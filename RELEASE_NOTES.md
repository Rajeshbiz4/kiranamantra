# KiranaMitra 1.0.0

Offline desktop billing and store-management release with SQLite persistence, GST invoices, products, customers, suppliers, purchases, stock movements, returns, ledgers, expenses, cash register, batch/expiry controls, password security, role permissions, backups, CSV import/export and business reports.

Validation completed: TypeScript checking, unit tests, production web build and database migrations through schema version 10.
